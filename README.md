## ⚡ Ключевые возможности

* 🛑 **Авто-стоп минусовых адсетов:** Мгновенная остановка групп объявлений (AdSets) при превышении лимитов спенда без конверсий.
* 🟢 **Ловля «долетающих» конверсий (Delayed Attribution):** Если отключенный адсет получил отложенный лид/регистрацию в пикселе и CPA вошел в норму — бот шлет алерт с кнопкой **`[✅ Включить адсет]`**.
* 🚀 **Учет часовых поясов и 00:00 Пуш:** Отслеживание сброса суток по локальному времени каждого кабинета и пуш-уведомление при первом показе рекламы.
* 💵 **Моментальный подсчет расходов:** Срез суммарного спенда по всем кабинетам в 1 клик с пометкой статусов в Meta.
* 📊 **Аналитические сводки за периоды:** Моноширинные сводки за **Сегодня / Вчера / 3 дня / 7 дней** с дедупликацией лидов, регистраций и покупок.
* 📋 **Умный парсер кабинетов:** Распознавание сырого текста из Facebook Business Manager (авто-поиск `act_...` и сопоставление названий).
* 🛡 **Безопасный режим:** Новые кабинеты по умолчанию подключаются только для сбора статистики; автоправила включаются индивидуальным тумблером.
* 👑 **Мульти-пользовательский режим & Whitelist:** Разделение кабинетов по байерам, система подтверждения заявок администратором.

## 📐 Ступенчатая логика авто-правил

Все расчеты ведутся в **USD ($)** на уровне **AdSet**:

| Ступень | Состояние адсета | Условие срабатывания | Действие системы |
|---|---|---|---|
| **Ступень 1** | 0 лидов / рег | Спенд $\ge \$2.00$ | 🛑 **PAUSE в Meta** + мгновенный алерт в Telegram |
| **Ступень 2** | 1 лид / рега | Спенд $\ge \$6.00$ | 🛑 **PAUSE в Meta** + алерт в Telegram |
| **Ступень 3** | 2+ лида / рег | CPA $> \$6.00$ | 🛑 **PAUSE в Meta** + контроль допустимого CPA |
| **Реактивация** | Был выключен $\rightarrow$ Долетел результат | Итоговый CPA $\le \$6.00$ | 🟢 **PROPOSE_REACTIVATE** (интерактивная кнопка в TG) |

> 💡 *Пороговые значения лимитов ($2 / $6 / $6) настраиваются индивидуально для каждого кабинета кнопками быстрых пресетов или вручную.*

## 📱 Интерфейс Telegram-бота

### Главное меню и команды

| Кнопка / Команда | Описание |
|---|---|
| **`📊 Сводка`** (`/summary`) | Сводный отчет за **Сегодня / Вчера / 3 дня / 7 дней** (спенд, клики, лиды, реги, покупки). |
| **`💵 Расходы`** (`/spend`) | Моментальный срез расходов за сегодня по всем кабинетам с пометкой статусов в Meta. |
| **`🏢 Мои кабинеты`** (`/accounts`) | Карточки кабинетов: тумблер авто-правил, настройка лимитов, статус токена, удаление. |
| **`⚙️ Настройки`** (`/settings`) | Выбор интервала фонового опроса: **10 мин / 15 мин / 30 мин / 60 мин**. |
| **`➕ Добавить кабинеты`** (`/add`) | Пошаговый FSM-мастер добавления пакета аккаунтов с умным парсингом FB BM. |
| **`🔑 Инструкция по токену`** | Пошаговый гайд по генерации бессрочного System User токена в Meta Business Manager. |
| **`👑 Админ-панель`** (`/admin`) | Управление заявками на доступ (Whitelist), смена ролей, просмотр аудит-логов (`/events`). |

## 🚀 Быстрый старт

### Требования
* Python 3.12+
* Токен Telegram-бота от [@BotFather](https://t.me/BotFather)
* Доступ к Meta Business Manager (System User Token)

### Локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone git@github.com:hiurano/buyerly.git
   cd buyerly
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   # Отредактируйте BOT_TOKEN и ADMIN_CHAT_ID в .env
   ```

4. **Запустите тесты:**
   ```bash
   python -m unittest discover tests -v
   ```

5. **Запустите приложение:**
   ```bash
   python main.py
   ```

---

### Запуск через Docker Compose

```bash
# Сборка и запуск в фоновом режиме
docker compose up -d --build

# Просмотр логов в реальном времени
docker compose logs -f

# Остановка контейнера
docker compose down
```

## 🔄 CI/CD и Автодеплой

Проект оснащен автоматизированным CI/CD пайплайном через **GitHub Actions** ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)):

1. **Continuous Integration (CI):** При каждом push в `main` автоматически запускается полный набор unit- и e2e-тестов.
2. **Continuous Deployment (CD):** При успешном прохождении тестов код автоматически деплоится на Production VPS:
   * Создается снапшот базы данных (`scripts/backup_db.sh`).
   * Обновляется исходный код (`git reset --hard origin/main`).
   * Пересобирается Docker-контейнер (`docker compose up -d --build`).
   * Проверяется статус работоспособности.

Подробная инструкция по настройке секретов GitHub: [**`docs/DEPLOYMENT.md`**](docs/DEPLOYMENT.md).
