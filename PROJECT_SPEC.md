# AI Media Buyer — Спецификация и Архитектура проекта

> **Цель проекта:** Автономная система мониторинга, контроля рисков и автоматического управления рекламными кампаниями в Meta (Facebook Ads) с интеграцией в Telegram и n8n.

---

## 1. Контекст предметной области (Ликбез для разработчика)

### 1.1. Иерархия сущностей в Facebook Ads
1. **Ad Account (Рекламный кабинет, `act_<ID>`):** Контейнер с балансом/картой, часовым поясом и валютой.
2. **Campaign (Кампания):** Определяет общую цель (например, `OUTCOME_LEADS` — сбор заявок).
3. **AdSet (Группа объявлений):** **Ключевая рабочая единица!** Здесь настраиваются таргетинг (ГЕО, возраст, интересы), дневной бюджет и оптимизация.
4. **Ad (Объявление / Креатив):** Текст, видео/картинка, ссылка на лендинг.

### 1.2. Основные метрики (Insights)
* **Spend (Спенд):** Сколько денег уже открутил адсет за сегодня.
* **Impressions / Clicks:** Показы и клики по объявлению.
* **CTR (Click-Through Rate):** Кликабельность ($Clicks / Impressions \times 100\%$).
* **CPC (Cost Per Click):** Цена одного клика ($Spend / Clicks$).
* **Leads (Лиды / Конверсии):** Количество полученных заявок/покупок (регистрируются через Facebook Pixel / Conversions API).
* **CPA / CPL (Cost Per Action / Cost Per Lead):** Цена одного лида ($Spend / Leads$).

## 2. Боли медиабайера (User Problems)

| № | Проблема / Боль | Как происходит сейчас | К чему приводит |
|---|---|---|---|
| **1** | **Постоянный ручной мониторинг** | Байер каждые 15–30 минут заходит в десятки профилей антидетект-браузера и жмёт F5. | Трата 70% рабочего времени на рутину вместо тестов и связок. |
| **2** | **Сливы бюджета при задержке** | Если байер отошёл на 40 минут, зацепившийся в минус адсет продолжает крутить. | Прямой убыток $20–$100 на кабинет за один пропуск. |
| **3** | **Рутина настройки автоправил** | Настройка правил в UI Facebook занимает 10 минут на кабинет. При 20 кабинетах под разные ГЕО — это часы кликов. | Ошибки в цифрах, человеческий фактор, пропуск аккаунтов. |
| **4** | **«Долет лидов» (Delayed Attribution)** | Адсет выключили (спенд $15, 0 лидов). Через 25 мин долетает задержавшийся лид ($15 за лид — норма). Адсет стоит выключенным. | Упущенная прибыль. Связка простаивает, байер не знает о лиде. |
| **5** | **Отсутствие единого пульта** | Нет сводки по всем аккаунтам в одном месте. | Приходится перебирать вкладки браузера. |

## 3. Решение: Функциональные требования

### 3.1. Модуль шаблонов правил (Rule Presets)
Позволяет создавать пресеты параметров под разные ГЕО/офферы (например, `Tier-1_Search_CPA_15`, `Tier-3_Latam_CPA_3`).

**Пример структуры пресета:**
```json
{
  "preset_id": "tier1_aggressive",
  "name": "Tier-1 Агрессивный стоп",
  "currency": "USD",
  "rules": [
    {
      "type": "NO_LEADS_STOP",
      "condition": "spend >= 12.0 AND leads == 0",
      "action": "PAUSE",
      "notify": true
    },
    {
      "type": "HIGH_CPA_STOP",
      "condition": "spend >= 25.0 AND cpa > 20.0 AND leads >= 1",
      "action": "PAUSE",
      "notify": true
    },
    {
      "type": "DELAYED_LEAD_REACTIVATE",
      "condition": "status == 'PAUSED' AND leads > 0 AND cpa <= 15.0",
      "action": "PROPOSE_ENABLE",
      "notify": true
    }
  ]
}
```

### 3.2. Фоновый мониторинг (Worker Engine)
* Каждые $N$ минут (например, 5–10 мин) опрашивает `Meta Marketing API` по всем подключенным кабинетам.
* Сравнивает текущие метрики за день (`date_preset=today`) с условиями активного пресета.
* При нарушении лимитов — отправляет запрос на изменение статуса (`POST /{adset_id} status=PAUSED`).

### 3.3. Умная реактивация («Долет лидов»)
* Сервис продолжает отслеживать адсеты, остановленные сегодня.
* Если пиксель зарегистрировал отложенный лид и `CPA` вошел в норму:
  * Отправляет в Telegram интерактивное сообщение с кнопками:
    `[ 🟢 Включить адсет обратно ]` `[ 🔴 Оставить выключенным ]`.
  * (Опционально) Автоматически переводит статус в `ACTIVE`.

### 3.4. Telegram-уведомления и Дайджесты
1. **Мгновенные алерты:**
   * 🛑 *«Отключен AdSet `AdSet_Broad_01` (Кабинет: `Acc #4`). Спенд: $14.50, Лидов: 0. Лимит: $12.00»*
   * 🟢 *«Долетел лид в `AdSet_Broad_01`! Спенд: $14.50, Лидов: 1, CPA: $14.50. Включить?»*
2. **Периодический дайджест (раз в 2-4 часа):**
   * Общий спенд по всем кабинетам, количество лидов, средний CPA, активные/стопнутые адсеты.

### 3.5. Интеграция с n8n и AI-агентами
* Предоставление простого REST API:
  * `POST /api/v1/accounts/attach` — привязать кабинет и токен к пресету.
  * `POST /api/v1/accounts/sync` — принудительная синхронизация.
  * `GET /api/v1/reports/summary` — получение сводки для n8n/дашборда.
