## Запись №12: Мульти-пользовательская архитектура, безопасность (Whitelist) и пакетный мастер
* **Дата:** 16.08.2026
* **Статус:** Реализовано, покрыто 10 тестами, запущено в онлайне.

### Реализованные решения:
1. **Пошаговый FSM-мастер добавления кабинетов (включая пачки):**
   * Шаг 1: Пользователь отправляет список ID (1 или пачку из 5-20 шт).
   * Шаг 2: Пользователь задает имя пачки (например, `Швеция` $\rightarrow$ бот автоматически нумерует `Швеция 1`, `Швеция 2`...) либо ставит `-` для сохранения оригинальных имен из FB.
   * Шаг 3: Отправляет один Access Token системного пользователя.
   * Бот проверяет кабинеты в Meta API, сохраняет их и ставит на мониторинг.
2. **Безопасность и Белый список (Admin Whitelist):**
   * Доступ в бота закрыт для посторонних.
   * Новые пользователи видят экран ожидания, а Главному Админу прилетает интерактивный пуш с кнопками `[✅ Одобрить доступ]` / `[❌ Отклонить]`.
3. **Изоляция данных по байерам (Multi-Tenancy):**
   * Каждый кабинет привязывается к `owner_id` (Telegram ID байера).
   * Кнопки `📊 Сводка`, `💵 Расходы`, `🏢 Мои кабинеты` показывают только данные конкретного байера.
   * Персональные алерты о стопах и долетах уходят строго владельцу кабинета.
   * Главному Админу доступна кнопка `👑 Админ-панель` со статистикой по всей команде.
