## Запись №1: Источник задачи и первичные требования
* **Дата:** 16.08.2026
* **Входные данные:** Голосовое сообщение заказчика (`audio_2026-08-16_01-09-55.ogg`, 3 мин 02 сек).
* **Стенограмма:** Расшифрована локально через `faster-whisper` в изолированном `.venv` (сохранена в `transcription.txt`).

### Выделенные боли и цели заказчика:
1. Медиабайер тратит 70% времени на ручной мониторинг десятков рекламных кабинетов в антидетект-браузере каждые 15–30 минут.
2. Ручная настройка нативных автоправил Facebook на 15–20 кабинетов под разные ГЕО — монотонная и долгая рутина.
3. Проблема отложенных конверсий («долет лидов»): при остановке адсета без лидов через 20–30 минут может догрузиться задержавшийся лид, делая связку прибыльной, но в стандартном FB она остается выключенной.
4. Необходим инструмент, который автоматически мониторит кабинеты, вовремя останавливает убыточные группы объявлений, ловит долетающие лиды и шлет отчеты/алерты.

## Запись №9: Расширенный функционал и новые требования заказчика
* **Дата:** 16.08.2026
* **Входные данные:** Обсуждение итогов MVP с заказчиком.

### Принятые архитектурные решения:
1. **Гибкие сводки и подсчет расходов:**
   * Кнопка **«📊 Сводка»** с интерактивным выбором периодов: `[ Сегодня ]`, `[ Вчера ]`, `[ За 3 дня ]`, `[ За 7 дней ]`.
   * Отдельная кнопка **«💵 Расходы»** — моментальный подсчет суммарных затрат по всем кабинетам в 1 клик.
2. **Учет «Регистраций» (CompleteRegistration) наравне с лидами:**
   * В ступенях правил и метриках события конверсий разделяются/агрегируются (лиды + регистрации).
3. **Гибкая настройка правил для каждого кабинета (без обязательных шаблонов):**
   * Упрощенный формат добавления: `/add act_ID Имя Токен`.
   * Возможность прямо из Telegram настраивать индивидуальные пороги ($2 / $6 / $6 или кастомные) для конкретного кабинета.
4. **Управление частотой проверки (Интервалы опроса):**
   * Выбор интервала прямо из меню Telegram-бота: `[ 10 мин ]`, `[ 15 мин ]`, `[ 30 мин ]`, `[ 60 мин ]` (интервал 5 минут исключен по требованию).
5. **Единая валюта:**
   * Строго доллары США (**$ USD**).
6. **Учет часовых поясов кабинетов (Timezone) и Пуш о старте открута (00:00):**
   * Система автоматически определяет часовой пояс кабинета (например, `HST`, `PST`, `UTC+3`).
   * При наступлении 00:00 по времени кабинета и начале первых показов ($Spend > 0$) бот присылает пуш: 🚀 *«Кабинет X начал открут рекламы! Активных адсетов: Y, Стартовый спенд: $Z»*.

## Запись №11: Защитные алерты здоровья кабинетов и токенов в Meta
* **Дата:** 16.08.2026
* **Статус:** Реализовано и покрыто тестами.
* **Функционал:**
  - Автоматическая валидация `account_status` в Meta API (1: Активен, 2: Бан / Policy, 3: Hold / Биллинг, 7: Risk Review и др.).
  - При обнаружении проблемы бот отправляет критический алерт в Telegram и приостанавливает опрос проблемного кабинета во избежание сбоев.
  - При ошибке `190 OAuthException` (слетевший/истекший токен) бот отправляет алерт с инструкцией по быстрому обновлению токена через `/add`.
