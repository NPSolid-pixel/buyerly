# План реализации 86eyr5z4r

## Цель

Сделать URL воркспейсов воспроизводимыми, безопасными для системных маршрутов и
устойчивыми к одновременному созданию одинаковых названий.

## Контракт

- Один нормализатор для API, онбординга, первого воркспейса и frontend-preview.
- ASCII lowercase, дефисы, не более 60 символов; кириллица транслитерируется.
- Системные маршруты не выдаются пользователям и получают `-workspace` при создании.
- Совпадения получают минимальный свободный числовой суффикс: `name`, `name-2`,
  `name-3`.
- Выбор суффикса сериализуется PostgreSQL advisory transaction lock.
- Старые записи нормализуются отдельной идемпотентной Alembic-миграцией.

## Проверка готовности

- Контрактные и интеграционные тесты покрывают транслитерацию, системные пути,
  длину, одновременное создание и отсутствие перезаписи.
- Полный GitHub Actions pipeline проходит до слияния.
- Production deploy подтверждает точный SHA и успешный readiness-check.
