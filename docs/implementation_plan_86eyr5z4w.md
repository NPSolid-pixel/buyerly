# План реализации 86eyr5z4w

## Цель

Не допускать пустого экрана при повреждённой или недоступной browser storage и
сохранять все остальные корректные пользовательские настройки.

## Контракт

- Каждая стартовая настройка читается независимо от остальных.
- Ошибка доступа, невалидный JSON или неверная структура сбрасывают только
  соответствующий ключ.
- Массивы, словари, направления и режимы сортировки проверяются до помещения в
  состояние приложения.
- Сброшенная настройка получает безопасное значение по умолчанию без перезагрузки.
- Валидные сохранённые настройки не изменяются.
- Ошибка записи не отменяет уже выполненное действие в текущем интерфейсе.

## Проверка готовности

- JavaScript проходит синтаксическую проверку.
- Контрактный тест запрещает прямой стартовый `JSON.parse(localStorage.getItem(...))`
  и фиксирует проверку форматов для всех сохранённых настроек.
- Полный GitHub Actions pipeline проходит до слияния и production deploy.
