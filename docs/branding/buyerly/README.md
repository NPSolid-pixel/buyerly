# Buyerly Official Brand Assets — The Doberman «B» Mark

Официальный утверждённый логотип и фирменный знак платформы **Buyerly**.
Синтез геометрии **Attio**, маскота-добермана команды **Underdog** и монограммы буквы **«B»**.
