# Attio Brand Assets (Логотипы и знаки)

Официальные векторные ассеты бренда Attio, полученные из официального брендбука ([attio.com/brand](https://attio.com/brand)).

## 📁 Доступные файлы

Файлы сохранены в двух директориях проекта:
1. `docs/branding/attio/`
2. `webapp/icons/attio/`

---

### 1. Знак (Logomark / Icon)
* **`attio-logomark-black.svg`** — Черный знак (`#000000`) для светлого фона.
* **`attio-logomark-white.svg`** — Белый знак (`#FFFFFF`) для темного фона.
* **`attio-logomark-adaptive.svg`** — Адаптивный знак (`currentColor`) для CSS-тем.

### 2. Полный логотип (Lockup: Знак + Текст "attio")
* **`attio-lockup-black.svg`** — Черный полный логотип (`#000000`).
* **`attio-lockup-white.svg`** — Белый полный логотип (`#FFFFFF`).
* **`attio-lockup-adaptive.svg`** — Адаптивный полный логотип (`currentColor`).

### 3. Только шрифтовая часть (Wordmark Only: "attio")
* **`attio-wordmark-black.svg`** — Черная шрифтовая часть (`#000000`).
* **`attio-wordmark-white.svg`** — Белая шрифтовая часть (`#FFFFFF`).
* **`attio-wordmark-adaptive.svg`** — Адаптивная шрифтовая часть (`currentColor`).

### 4. Иконки приложений / Бейджи (App Icon / Favicon Badge)
* **`attio-app-icon-dark.svg`** — Темный квадратный бейдж (64×64) со скругленными углами (iOS/macOS стиль).
* **`attio-app-icon-light.svg`** — Светлый бейдж (64×64) с мягким серым фоном.
* **`attio-app-icon-white.svg`** — Чисто белый бейдж (64×64) с тонкой рамкой.
