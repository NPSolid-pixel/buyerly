# Underdog Media Buying Brand Assets

Логотипы и графические ассеты команды **Underdog Media Buying**, спарсенные с сайта [underdog.click](https://underdog.click/).

## 📁 Директории

1. `docs/branding/underdog/`
2. `webapp/icons/underdog/`

## 🎨 Список ассетов

### 1. `underdog-logo-full.png` / `underdog-logo-full.svg`
* **Описание**: Основной полноразмерный логотип Underdog (стилизованная типографика "UNDERDOG" + собака/символ).
* **Размеры**: 658 × 224 px.
* **Формат**: PNG с прозрачностью (RGBA) + векторный SVG-контейнер.

### 2. `underdog-logo-icon.png` / `underdog-logo-icon.svg`
* **Описание**: Логотип из хедера и фавикон сайта.
* **Размеры**: 99 × 84 px.
* **Формат**: PNG с прозрачностью (RGBA) + векторный SVG-контейнер.

### 3. `underdog-d-logo.png` / `underdog-d-logo.svg`
* **Описание**: Детализированный крупный логотип/фон из CSS-стилей сайта.
* **Размеры**: 276 × 259 px.
* **Формат**: PNG с прозрачностью (RGBA) + векторный SVG-контейнер.
