# BL-102: информационная архитектура, терминология и локализация

ClickUp: `86eyrx9bz`

## Цель

Собрать Buyerly вокруг задач медиабайера, сохранить совместимость существующих ссылок и закрепить русский как основной язык продукта.

## Реализация

1. Ввести шесть верхнеуровневых разделов: Сегодня, Эффективность, Автоматизации, История действий, Подключения, Настройки.
2. Добавить translation layer с единым словарём навигации и сущностей.
3. Сохранить старые URL как совместимые aliases, а новые URL сделать каноническими.
4. Добавить поиск на экран длинного списка подключений.
5. Зафиксировать терминологию, роль-зависимую видимость и шаблон длинных списков.
6. Защитить IA frontend- и documentation-контрактами.

## Проверка

- Статическая проверка JavaScript, Python и shell.
- Контракт новых и legacy URL.
- Контракт порядка desktop/mobile навигации.
- Полный GitHub Actions CI перед merge.
