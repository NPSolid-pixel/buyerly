# 🔑 Полная инструкция: Как получить вечный Access Token в Meta Business Manager

Этот токен (**System User Access Token**) является бессрочным (не протухает через пару часов) и позволяет боту безопасно читать статистику и управлять адсетами рекламных кабинетов.

---

## 📌 Пошаговый план (занимает ~3 минуты)

### Шаг 1: Создание приложения в Meta Developers
*(Если приложение уже создано в Business Manager — переходите к Шагу 2).*

1. Перейдите на портал разработчиков: [developers.facebook.com/apps](https://developers.facebook.com/apps).
2. Нажмите зеленую кнопку **«Create App» (Создать приложение)**.
3. Выберите тип: **«Other» (Другое)** $\rightarrow$ нажмите **Next**.
4. Выберите назначение: **«Business» (Для бизнеса)** $\rightarrow$ нажмите **Next**.
5. Заполните данные:
   * **App Name (Название):** `Buyerly Ads Automation` (или любое понятное имя).
   * **Business Account:** выберите ваш Business Manager (Бизнес-портфолио).
6. Нажмите **«Create App»**.

---

### Шаг 2: Создание System User (Системного пользователя)
1. Откройте настройки вашего Business Manager: [business.facebook.com/settings](https://business.facebook.com/settings).
2. В левом меню перейдите в раздел: **Users (Пользователи)** $\rightarrow$ **System Users (Системные пользователи)**.
3. Нажмите кнопку **«Add» (Добавить)**:
   * **System Username:** `Buyerly Bot`
   * **System User Role:** выберите **Admin (Администратор)**.
4. Нажмите **«Create System User»**.

---

### Шаг 3: Выдача прав на Рекламные Кабинеты (Assign Assets)
1. В списке системных пользователей выберите созданного `Buyerly Bot`.
2. Нажмите кнопку **«Assign Assets» (Назначить объекты)**.
3. В левой колонке выберите **Ad Accounts (Рекламные аккаунты)**.
4. Отметьте галочками все рекламные кабинеты, которые должен контролировать бот.
5. В правой колонке включите тумблер: **Full Control / Manage Campaigns (Полный контроль / Управление кампаниями)**.
6. Нажмите кнопку **«Save Changes» (Сохранить изменения)**.

---

### Шаг 4: Генерация бессрочного токена (Access Token)
1. Там же, в карточке системного пользователя `Buyerly Bot`, нажмите кнопку **«Generate New Token» (Создать новый токен)**.
2. В выпадающем списке **Select App** выберите приложение, созданное в Шаге 1 (`Buyerly Ads Automation`).
3. В поле **Token Expiration (Срок действия)** выберите: **Never (Бессрочный)** или **60 days**.
4. В списке разрешений (**Permissions**) отметьте ровно 2 галочки:
   * ✅ **`ads_management`** (для автоматического отключения/включения адсетов);
   * ✅ **`ads_read`** (для сбора спенда, лидов, регистраций и CPA).
5. Нажмите кнопку **«Generate Token»**.
6. Появится окно с готовым токеном (начинается на `EAAM...`). **Скопируйте его и сохраните**.

---

## 🚀 Подключение кабинета в бота

Когда токен получен, добавление кабинета в Telegram-боте занимает 5 секунд:

```text
/add act_ID_КАБИНЕТА НАЗВАНИЕ ВАШ_ТОКЕН
```

*Пример:*
```text
/add act_1083480094013618 Швеция_3286 EAAM4nhbU7CcBS...
```
